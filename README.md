#  Customer Churn Analysis & Retention Strategy

In this project, I worked on analyzing customer churn data using SQL and Python to figure out why users were dropping off and how the business can retain them better.

##  What Problem Am I Solving?
Losing customers directly hits business revenue. The main goal here was to dig into customer data and answer two main questions:
* **Who** is leaving or about to leave?
* **Why** are they leaving? (Looking at patterns around subscription types, usage habits, and customer tenure).

##  Tools & Tech Used
* **SQL:** To query and pull raw customer data directly into Python.
* **Python:** For cleaning, analyzing, and plotting the data.
* **Libraries:** `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`.
* **Jupyter Notebook:** To write and structure the workflow.

##  How I Approached This
1. **Data Pulling:** Hooked up Python with the SQLite database to fetch raw tables.
2. **Data Cleaning:** Cleaned up missing entries, fixed data formats, and prepared features for analysis.
3. **Exploratory Analysis:** Found an overall churn rate of ~28.6% and analyzed how factors like tenure and plan types impact drop-off rates.
4. **Actionable Insights:** Wrapped up with specific recommendations to help the product/business team target high-risk users early.
